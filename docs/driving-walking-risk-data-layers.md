# Sunny SAI · 자동차/도보 위험판단 분리 및 TAAS 지도레이어

## 위험판단 입력의 구분

| 위험판단 | 입력 데이터 | 화면 |
|---|---|---|
| 자동차(Driving) | 기상청 경로 예보·특보·검증된 도로위험기상 및 ITS 사고·공사·통제 | **지도에 표시** |
| 도보(Walking) | TMAP 실제 도보 경로/횡단보도/계단 등의 보행시설, TAAS 과거 보행 사고이력(REST 수신 확인 시) | **교통·보행 정보** |
| 공통 환경 | 시각·위치가 확인된 강수, 눈, 고온 등 기상예보 | 이동수단 특성에 맞게 사용 |

- `evaluateDrivingRisk` / `evaluateWalkingRisk`로 실제 판단 진입점을 구분한다.
- 자동차 엔진은 과거 보행자 사고다발지역을 자동차 사고·통제로 오인하지 않는다.
- 도보 엔진은 ITS 자동차 돌발신고나 도로용 결빙 위험지수를 보행로 통제·위험으로 사용하지 않는다.
- 도로 링크 및 진행방향 일치가 확인되지 않은 ITS 신고는 **경로 인접 주의**까지만 표출하며 자동 우회 근거로 사용하지 않는다.

## 새 지도 표출 항목

교통·보행 정보 그룹에 **승인받은 한국도로교통공단 TAAS 2024년 WMS 3종**:

1. `navLayerPedestrianWms`: 보행자 사고다발지역 (`frepedstrians`)
2. `navLayerChildWms`: 어린이 보행 사고다발지역 (`frechild`)
3. `navLayerElderlyWms`: 노인 보행 사고다발지역 (`freoldman`)

지도는 카카오맵의 실제 좌표 투영을 사용해 WMS PNG를 지도 위의 올바른 지리 범위에 겹친다. 지도 이동·줌 시 갱신한다. 표출은 기본 OFF이며, 승인키가 있는 경우에만 ON 가능하다.

### 현재 범위 제한 (중요)

- 지도 중심 좌표에 해당하는 **법정 시군구 1개**만 조회한다. 여러 시군구에 걸친 지도 영역을 빠짐없이 표출하는 전국 서비스는 아직 아니다.
- 너무 넓거나 극단적으로 좁은 지도 축척에서는 조회하지 않는다. WMS 요청 범위는 한 번에 최대 경도·위도 각 0.20도로 제한한다.
- PNG 이미지에 있는 개별 사고 위치·건수를 AI가 정확하게 추출했다고 주장하지 않는다. **이미지 표출과 숫자 기반 위험판단은 다르다.**
- REST 보행자 사고다발지역은 과거 라이브 프리뷰 검사에서 기관 응답코드 확인 실패. 별도 REST 승인·응답검증 후에만 경로별 AI 사고이력 점수를 사용할 수 있다.
- TMAP의 보행시설(횡단보도·계단 등)은 위치정보이지 사고관측 또는 위험수준 자체가 아니다.

## 서버와 개인정보/보안

- `POST /api/taas-pedestrian-map`, 필수: 동일 출처 로그인 세션·CSRF, `{kind: pedestrian|child|elderly,bounds: {west,south,east,north}}`.
- 서버가 카카오 좌표→법정구역으로 조회 코드를 결정하고, TAAS WMS 고정 URL·레이어 이름·2024년을 사용한다.
- PNG MIME·서명·용량 검사 후에만 이미지를 브라우저에 보낸다. `KOROAD_API_KEY`와 `KAKAO_REST_API_KEY`는 브라우저에 전달하지 않는다. 호출 횟수 제한 적용.
- ITS는 자동차 '지도에 표시' 그룹으로 이동. TAAS 보행정보와 혼합하지 않는다.

## 배포 이전 남은 실제 검증

- 최신 GitHub 개발 브랜치 자동 테스트와 빌드 통과 확인.
- 사용자 배포 요청 및 Vercel 배포 한도 회복 후 **고정 프리뷰에만** 최신 커밋 배포.
- 보행자/어린이/노인 WMS를 실제 인증키로 각각 PNG 수신 테스트하고 카카오지도 좌표 정합·투명도·이동/확대/축소 확인.
- 서울역→서울시청 TMAP 도보경로의 TAAS 레이어 표시와 실제 사고이력 REST 승인 여부 확인.
- 서울시청→부산시청 차량경로의 ITS 신고 표시, 자동차 엔진에서 보행자 통계 제외 여부 확인.
- 운영 도메인은 사용자에게 별도 승인을 받은 경우에만 배포.
