# Sunny SAI LLM 상황 브리핑·판정 근거 설명

## 구현 범위

- 경로 탐색 결과와 이동 중 화면의 ‘판단 근거’에서 현재 엔진 결과를 설명한다.
- 환경설정에서 자동 브리핑을 선택하면 새 판정 발생 시 설명을 요청한다. 자동 요청은 최소 60초 간격이며 위험 엔진이나 기존 음성 안내를 기다리게 하지 않는다.
- 더미 모드에서는 브리핑과 모델·선택 근거·대체 여부가 실행 기록 JSON에 남는다.
- LLM은 엔진이 제공한 승인 문장의 ID를 선택·배열한다. 자유 서술이나 위험등급 생성 기능이 아니다. 수치·위험 종류·조치 변경, 미확인 근거, 필수 불확실성 문구 누락은 거절한다.
- 서버가 입력받는 것은 브라우저 엔진의 판정 스냅샷이다. 공급기관 자료 진위나 현장 상태를 LLM이 재검증하는 기능은 아니다.

## 개인 키로 Gemini 연결

1. 환경설정 → ‘LLM 상황 브리핑·근거 설명’에서 Google Gemini를 선택한다.
2. 자신의 계정에서 사용 가능한 모델 ID와 Gemini API 키를 입력하고 ‘임시 연결·모델 변경’을 누른다.
3. 키 등록은 실제 응답 검증이 아니다. 경로를 탐색한 후 ‘왜 이렇게 판단했나요?’에서 요청한다.
4. 성공 시 ‘LLM 응답 검증 완료 · gemini / 모델ID’가 표시된다. 실패 시 ‘정형 근거 설명’과 대체 사유가 표시된다.
5. 같은 제공자의 다른 모델 ID로 바꾸고 연결 버튼을 누르면 저장된 임시 키를 재사용한다. 각 모델에서 실제 요청을 수행하고 결과를 기록해야 2종 구동 검증이라고 할 수 있다.
6. 키는 최대 30분 암호화된 HttpOnly 쿠키에 저장한다. 채팅, 저장소, 브라우저 localStorage에는 기록하지 않는다.

## 운영자 환경변수 연결

```
LLM_PROVIDER=gemini
LLM_MODEL=<계정에서 사용 가능한 모델 ID>
LLM_API_KEY=<운영자가 비밀 환경변수로 등록>
```

호환 API 어댑터:

```
LLM_PROVIDER=compatible
LLM_MODEL=<서버가 제공하는 모델 ID>
LLM_BASE_URL=https://<운영자가 승인한 추론 서버>/v1
LLM_API_KEY=<운영자가 비밀 환경변수로 등록>
```

호환 API는 `/chat/completions`와 JSON 응답을 지원해야 한다. EXAONE 등 특정 모델이나 행정안전부 공통기반의 실제 서비스 이용 권한·호환성은 별도 확인이 필요하다. 임의의 제공자 URL을 사용자 브라우저에서 입력받지 않는다.

## 데이터·실패 처리

- 모델 제공자에게 최소 판정 근거 문장과 선택 질문을 보낸다. GPS 좌표, 목적지, 경로 형상, 원본 공급기관 서술문은 보내지 않는다.
- 위험판정 엔진을 실행한 뒤 설명을 비동기로 요청한다. 지연·타임아웃·키 누락·호출 제한·응답 검증 실패 시 정형 설명을 사용한다.
- 화면과 실행 기록에 `llm`과 `template`을 구분하고 모델 ID·제공자·근거 ID를 남긴다.
- 설명 요청 중 판정이나 경로가 바뀌면 이전 응답은 화면에 적용하지 않는다.
- 키 등록·모델 선택 화면, 실제 검증 성공 화면, 실패 시 대체 화면을 시연자료에 포함하면 된다.

## 검증 상태

어댑터 계약시험은 가짜 API 응답으로 Gemini와 호환 API의 요청·응답, 근거 검증, 비밀키 보호, 장애 대체를 확인한다. 실제 유료/외부 모델 연결 성공이나 두 실제 모델의 성능 검증을 뜻하지 않는다. 실제 키와 사용 가능한 모델 ID를 연결한 뒤 추가 확인해야 한다.
