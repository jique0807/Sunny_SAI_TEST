# Sunny SAI 교체형 LLM 설명 모델 (2026-11-11)

## 모드와 책임 분리

환경설정 → 전방 기상안내 → **LLM 설명 모델**에서 네 모드를 선택합니다.

- **LLM 미사용 (기본)**: 외부 LLM 호출 없이 엔진이 확인한 승인 문장으로 정형 설명을 표시합니다.
- **Gemma**: 별도 운영자 API 키와 승인된 OpenAI 호환 추론 서버를 이용하여 승인 문장 ID만 선택합니다.
- **GPT-OSS**: Gemma와 구분되는 모델 ID와 독립된 서버·키를 이용합니다. 동일한 설명 출력 계약을 실행합니다.
- **기존 개인 모델 연결**: 종전 Gemini 및 운영자 호환 API 임시 연결을 유지합니다.

LLM 선택은 위험판단 정책(기본 검증·강화 검증)과 독립적입니다. 자동차·도보 엔진의 근거·위험등급·안전판정·우회 여부는 LLM이 바꿀 수 없습니다.

## Vercel 서버 환경변수

모델 제공자가 발급한 **실제 모델 ID**와 HTTPS 호환 API 주소·서버 비밀키를 Preview 환경에 먼저 등록합니다. Production은 승인 전 변경하지 않습니다.

```text
LLM_GEMMA_MODEL=<실제 Gemma 모델 ID>
LLM_GEMMA_BASE_URL=https://<Gemma 추론 서버>/v1
LLM_GEMMA_API_KEY=<Gemma 비밀키>
LLM_GPT_OSS_MODEL=<실제 GPT-OSS 모델 ID>
LLM_GPT_OSS_BASE_URL=https://<GPT-OSS 추론 서버>/v1
LLM_GPT_OSS_API_KEY=<GPT-OSS 비밀키>
```

각 서버는 OpenAI 호환 `/chat/completions` 및 JSON 객체 출력을 지원해야 합니다. 모델 ID는 운영자 제공자에서 실제로 사용 가능한 ID여야 합니다. 제공자 키·엔드포인트는 사용자 브라우저에 전송하지 않습니다. 개인 Gemini 연결은 기존 암호화 HttpOnly 임시 쿠키 방식 그대로 유지합니다.

## 검증 및 출품 증빙

1. 자동차·도보의 동일 위험판단 스냅샷을 **LLM 미사용 / Gemma / GPT-OSS** 세 모드로 평가합니다.
2. 모델 2종 각각 실제 요청 성공, 반환 모델 ID, 응답시간, 검증 통과 근거 ID를 기록합니다.
3. 허위 사실·필수 문장 누락·조치 변경·타임아웃·HTTP 장애·유효하지 않은 JSON은 폐기하고 정형 설명으로 대체합니다.
4. 각 모델의 실제 서비스 권한이 없다면 '설정됨'도 '실제 구동 검증 완료'로 표시하지 않습니다.
5. 비밀키·GPS 좌표·목적지·도로 좌표는 모델 요청과 출품 기록에 포함하지 않습니다.

**구현 시점 상태:** 코드 모드 교체 및 모의 응답 기반 자동시험은 가능하지만, 실제 Gemma와 GPT-OSS 서버 키/권한이 없으므로 2종 실호출은 아직 입증되지 않았습니다. 판정과 경로안내는 LLM 연결 실패에도 지속됩니다.

공식 참고: https://docs.vllm.ai/en/stable/serving/openai_compatible_server/ , https://ai.google.dev/api/generate-content

## Preview 전용 실제 모델 접속 진단 (준비 코드)

환경설정에서 **Gemma** 또는 **GPT-OSS**를 선택한 뒤 **선택한 모델 실제 연결 시험** 버튼을 직접 누르면, `POST /api/llm/diagnostic`으로 고정된 허구 자료에 대해 1회 호출합니다.

- 실제 GPS, 경로, 목적지, 제공자 원자료, 사용자 질문, API 키는 보내지 않습니다.
- Preview 전용이며 세션·CSRF·요청 횟수 제한을 적용하고, 자동/정기 호출은 없습니다.
- 응답 문장 ID·필수 근거·위험판정 조치의 서버 검증에 통과해야 `verified=true`입니다. HTTP 응답 성공과 환경변수 등록만으로는 통과하지 않습니다.
- `requestedModel`은 설정된 모델 ID, `reportedModel`은 제공자가 회신한 모델 ID입니다. 둘이 다르거나 제공되지 않은 경우 모델 동일성이 확인된 것으로 처리하지 않습니다.
- 실제 공급자 연결 실패 시 정형 설명으로 대체하며 위험판정 엔진·우회 경로는 변경하지 않습니다.
- 모델 서버 호출에는 과금이 발생할 수 있으므로 사용자의 명시적 클릭으로만 시험합니다.
- 이 GitHub 변경은 배포 브랜치에 아직 적용하지 않았습니다. 따라서 실제 서비스 연결·실모델 응답 검증을 완료했다고 주장하지 않습니다.

**검증 기록 원칙:** Gemini/Gemma/GPT-OSS 모두 데모 모의 호출 통과와 외부 공급자 실호출 성공을 별도로 기록해야 합니다. 추후 실호출 시각, 선택 모델 ID, 응답 모델 ID(있을 때), 지연시간, 응답 검증 통과 여부, 검증 실패 이유만 남기고 인증키·좌표·사용자 입력은 기록하지 않습니다.

## 공급자 응답 오류 진단 보강 (2026-11-11)

- 제공자 HTTP 오류는 응답 본문을 노출하지 않고 상태 코드 및 안전한 종류만 표시합니다: 400/422 요청 형식, 401 인증, 403 권한, 404 모델·주소, 429 한도, 402 크레딧, 5xx 제공자 장애.
- OpenAI 호환 모델 요청에서 공급자마다 미지원할 수 있는 `temperature: 0`과 `response_format: json_object`를 제거해 기본 Chat Completions 계약만 사용합니다. 수신된 JSON·근거 문장 검증은 그대로 필수입니다.
- 표시되는 HTTP 상태는 외부 모델 제공자 응답 상태이며 Vercel 자체 장애 또는 계정 검증 성공을 의미하지 않습니다.
- 모델 호출 실패 시 기존 정형 설명으로 대체하고 자동차·도보 위험판단 로직은 변경하지 않습니다.
- 모델 서버 오류 본문, 인증키 및 API 주소는 시험 결과에 포함하지 않습니다.

## OpenRouter API 키 인증 사전검사

Preview 설정에서 Gemma 또는 GPT-OSS를 선택하면 `OpenRouter API 키 인증 확인` 버튼을 사용할 수 있습니다.

- OpenRouter가 공식 제공하는 `GET https://openrouter.ai/api/v1/key` API로 **키 자체를 확인**합니다. 모델 추론을 실행하지 않아 추론 토큰 비용이 발생하지 않습니다.
- `BASE_URL=https://openrouter.ai/api/v1` 및 `sk-or-` 접두부 여부를 먼저 검사합니다. 두 검사 모두 API 키 자체를 노출하지 않습니다.
- OpenRouter에서 인증 성공(HTTP 200)하더라도 선택 모델이 실제 추론 가능한지는 **별도의 실제 연결 시험**에서 검증해야 합니다.
- HTTP 401은 키 인증 거부, URL 불일치는 주소 설정, 다른 키 접두부는 제공자 불일치로 구분합니다.
- 진단 API는 Preview에서만, 세션 및 CSRF 확인 후, 요청 횟수를 제한해 동작합니다. 비밀 키·API 응답 본문·계정 메타데이터는 반환하지 않습니다.
- 위험판정 결과와 경로 탐색은 이 기능에서 읽거나 변경하지 않습니다.
