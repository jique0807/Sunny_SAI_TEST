# 지도 자료 정합 보완 — 2026-11-11

## 반영 사항

- 기상청 날씨누리에서 사용하는 공식 CRS84 특보구역 GeoJSON 393개를 원래 좌표 정밀도로 보관했다. 구역코드가 정확히 일치하는 경우에만 API 특보에 경계를 연결한다. 알 수 없는 코드는 경계 미확보로 남긴다.
- 카카오맵 Polygon으로 특보 경계와 내부 제외영역을 표시한다. 경로 선분의 구역 진입을 검사하며 대표점이 구역 밖에 있어도 중간 통과를 확인한다. 관측소 주변 500m를 특보구역으로 취급하던 경로 매칭을 제거했다.
- 특보구역 통과는 기상 주의 근거이며 도로 침수·통제를 확정하지 않는다. 발효 특보가 없는 경우 경계 표시 대상도 없다.
- 도로위험 진단에서 좌표가 있는 전체 링크 수와 표시 가능한 위험 레코드 수를 분리했다. 이미 적용된 공식 등급 정의를 진단에도 표시한다. 코드 0은 정보 없음이다.
- TAAS 경로 조회는 최대 6,000개의 실제 경로 좌표를 받는다. 2.5km 수집 필터를 대표점 주변이 아닌 전체 경로 선분에 적용한다. 최종 위험 아이콘은 기존 120m 경로 인접 조건을 유지한다. 조회한 대표 법정구역 밖까지 전국 완전탐색하는 기능은 아니다.
- 위성 진단에 영상 수신, 지도 중첩 준비, 위험판단 수치 입력 준비를 각각 표시했다. KO 900×922는 영상 원점과 22픽셀 영역의 공식 정의가 확인될 때까지 보류한다. CI ELA는 별도 투영·범위 정합이 필요하다.

## 위성 정합의 남은 조건

공식 문서: https://apihub.kma.go.kr/apiList.do?seqApi=6

이미지 다운로드는 실제 수신됐다. 그러나 이미지 크기만으로 지도 영역·여백 위치를 확정할 수 없다. 공식 이미지 영역 정의 또는 geolocation/투영 속성이 있는 원본 수치자료 확보 후 정합을 완료해야 한다. 이번 변경은 영상 중첩 완료나 수치자료 엔진 입력 완료를 의미하지 않는다.
