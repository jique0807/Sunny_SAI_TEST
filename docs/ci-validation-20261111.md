# CI 원본 정합 검증 — 2026-11-11

## 결론

수신한 ELA CI 원본(2026-11-11 04:42 UTC, 1200×1900)에 적용할 좌표변환을 구현하고 NMSC 공식 위경도 기준표 전체 2,280,000점을 비교했다. 실제 JavaScript 구현의 RMSE는 3.498328m, 최대 차이는 10.631456m, 99백분위는 6.910196m이다. 비정상 좌표는 0개였다. 최대 20m·RMSE 5m의 구현 검증 기준을 통과했다.

이 수치는 공식 표준 격자에 대한 계산 일치도이다. 위성 자체의 물리적 위치정확도·구름 높이 시차·탐지 정확도 또는 도로 위험 예측 정확도를 측정한 결과가 아니다.

## 독립 기준자료

- NMSC 공식 제공 목록: https://nmsc.kma.go.kr/homepage/html/base/cmm/selectPage.do?page=static.utilization.software
- GEOS 확장영역 2km 기준 좌표: https://nmsc.kma.go.kr/upload/resource/data/gk2a/gk2a_ami_ela020ge_latlon.nc
- SHA256: 96143a8a206c27a3602923dbde3e02b6c07c53012e213ec6aa65430d004ae839
- 기준표 크기와 CI 원본 크기는 모두 1200행×1900열이다. 원본 전체 좌표표 대신 재현에 필요한 체크섬·대표 기준점·결과 통계를 저장했다.

## 확인한 정합 조건

- 외부 함수 인자는 0부터 시작하는 배열의 픽셀 중심이다. NMSC 스캔각 계산에는 row+1, column+1을 적용해야 공식 좌표표와 일치한다. 이 한 칸을 생략하면 대표 위치에서 수 km 차이가 발생한다.
- 원본 CF 속성은 sweep_angle_axis=x지만 일반 PROJ geos sweep=x로 계산하면 기준표와 일치하지 않는다. 배열 중앙의 한 검증점에서 약 1,717m 차이가 발생했다. NMSC 공식 예제의 명시적 스캔 방정식 계열을 사용하고 실제 표준 좌표표로 검증했다. 일반 PROJ의 sweep=y는 같은 점에서 약 2.64m 차이로 기준표에 근접했다. 이 발견을 다른 위성·산출물의 임의 속성 수정 규칙으로 일반화하지 않는다.
- 현재 확인한 계수·영역 크기를 엄격히 검사하며 다른 계수나 1900×1230 PNG를 이 변환에 넣으면 거부한다.
- 모서리·서울/부산/제주 인접 격자·분수 픽셀 왕복변환·동서남북 축을 검사했다.
- 한국 도시의 최근접 격자 중심과 도시 좌표 사이 거리(수백m~1km)는 격자 표본화 거리이며 변환오차가 아니다.

## 데이터 의미와 품질

CI1_prob는 백분율이 아니다. 0=Non CI, 1=구름 미세물리 상태, 2=약한 상승, 3=중간 상승, 4=강한 상승의 범주이다. 255는 결측값이다.

DQF_CI1은 0=이전 객체 없음, 1=이전 객체 있음이다. 이전 객체가 없거나 품질코드가 비정상이면 추세 분석 입력을 보류한다. 비탐지·결측을 경로 안전으로 해석하지 않는다.

수신 표본에서 결측 2,216,620개, 범주 0~4와 이전 객체 존재 조건을 만족하는 픽셀은 63,161개였다. 이 숫자는 해당 시각의 전체 ELA 표본 통계이며 현재 사용자의 경로에 대한 위험 판정이 아니다.

## 재현

필요 패키지: Python numpy·h5py, Node.js.

```bash
python scripts/verify-ci-navigation.py \
  --reference /absolute/path/gk2a_ami_ela020ge_latlon.nc \
  --ci /absolute/path/received_ci.nc \
  --output /absolute/path/ci-verification.json
node --test test/gk2a-ci-navigation.test.mjs
```

검증 스크립트는 브라우저에서 사용할 실제 JavaScript 함수로 전체 픽셀 좌표를 계산해 독립 기준표와 비교한다. 지표는 근거리 위경도 차이를 미터로 환산한 값이다.
