# 위성 수치자료 지도·엔진 연결 — 2026-11-11

## 적용 코드

- 서버가 기존 KMA 키로 NC 파일을 수신하고 Node용 h5wasm 0.10.3에서 직접 읽는다. 키나 원본 NC 파일은 브라우저로 보내지 않는다.
- title·변수·격자 크기·투영계수·RR 배율을 실제 파일에서 검사한다. 확인한 계약과 다르면 해당 제품만 제외한다.
- `/api/satellite-map`은 인증된 요청의 현재 지도 범위에 맞는 지리좌표 사각형을 반환한다. 지도는 RR·CI·FOG를 각각 ON/OFF 할 수 있다. 광역 표시가 많으면 원본 블록 최대값으로 요약한다. 경로 분석은 요약하지 않은 원본 픽셀을 사용한다.
- `/api/satellite-route`는 경로 지점의 native pixel을 역변환해 읽는다. RR 구름유형, CI 이전 객체, FOG 품질코드의 서로 다른 의미를 보존한다.
- 지도 표시 OFF와 관계없이 2분 간격 경로 수집에 위성 항목을 연결했다. 기존 자동차·도보 시연은 실제 위성 입력에서 제외했다.
- 엔진에 satellite-rain / satellite-convection / satellite-fog의 관측 참고 신호를 추가했다. 기존 rain 예보와 별도 종류로 유지하며 위성 입력만으로 침수·통제·자동 우회를 만들지 않는다.
- 동일 제품·관측시각·원본 격자는 중복 경로 지점에서 점수를 중복 누적하지 않는다.

## 제외 조건

- 미수신, HDF5가 아닌 응답, 다른 산출물, 다른 격자/투영, 잘못된 RR 배율
- RR·CI 관측 20분 초과 / FOG 60분 초과(앱의 관측 신선도 정책)
- 결측·비정상 값, CI 이전 객체 없음, FOG 비정상 품질
- 예상 통과시각이 현재부터 15분보다 먼 경우: 관측자료를 장기 예보로 사용하지 않는다.

실패한 자료는 비·안개 없음이나 안전으로 처리하지 않는다. 다른 제품의 정상 자료까지 제거하지 않는다. 현재 수신 검증에서는 제품 전체를 영구 제외할 대상이 없었다. 경로별 CI 유효 픽셀이 없는 경우에는 그 경로의 CI 입력만 제외된다.

## 규칙 기준

RR ≥10mm/h는 주의, ≥30mm/h는 높은 강수 참고 신호이다. CI는 범주 2 약한 상승부터 참고하며 3·4는 주의이다. FOG 4는 안개 가능 참고, 5는 탐지 주의이다. 공식 특보나 사고확률이 아닌 앱 내부의 설명 가능한 관측 참고 기준이다. 시정(m), 노면 침수, 통제 여부를 위성값에서 만들지 않는다.

## 검증

- 실제 수신한 RR·CI·FOG NC를 새 Node 파서로 열어 배열·품질·좌표·지도 셀·경로 픽셀 조회를 확인했다.
- FOG 전체 810,000개 좌표를 NMSC KO LCC 기준표와 대조했다. 계산 차이 RMSE 0.5125m, 최대 1.3426m. 이는 기준표와의 일치도이며 위성 물리적 위치정확도가 아니다.
- 새 HDF5 검사, 잘못된 투영 거부, 지도 셀, 경로 원본 샘플, 자동차·도보 엔진 입력, 자동 우회 방지, 인증·CSRF, 한 제품 실패 시 다른 제품 유지, 오래되거나 잘못된 값 제외를 테스트했다.
- 전체 검사에는 기존 ITS 고정 시험자료의 종료시각 경과로 실패하는 검사 1개가 남아 있다.
- 배포용 빌드 성공. Node HDF5/WASM 런타임도 임시 Vercel 프리뷰에서 실제 동작했다.
