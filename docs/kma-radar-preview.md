# 기상청 초단기 강수예측 영상 — 프리뷰 1차 구현

## 구현 범위 (실제 API 연동)

- 카카오 지도에서 **📡 강수영상** 버튼 및 **표출 → 기상청 강수예측 영상 열기**를 제공합니다.
- 내비게이션 중에도 독립된 작은 영상창을 열 수 있습니다. 경로, GPS 및 우측 위험 예보 바는 유지됩니다.
- KMA 공식 API /api/typ03/cgi/rdr/nph-qpf_ana_img 의 실제 이미지 바이트만 프리뷰 서버에서 전달합니다.
- 요청 기준시각은 KST이며, 영상 생산 지연을 고려한 기준시각(현재 약 40분 전)을 요청합니다.
- 예측 리드 0/30/60/90/120분을 **실제 API 이미지가 수신된 경우에만** 표시합니다. 기본은 +60분입니다.
- 창이 열린 동안에만 5분마다 다시 조회합니다. 사용자 세션 인증, 분당 요청 제한, 3MiB 이미지 크기 제한, 서버 90초 캐시, 이미지 시그니처 검증을 적용합니다.
- API 키, 원본 API 오류 본문, 인증 URL을 브라우저에 노출하지 않습니다. 프리뷰 전용이며 Production에서는 404입니다.
- 실패/미수신 시 **영상 없음**을 표시하며 가상 강수영상을 노출하지 않습니다.

## 한계: 의도적으로 지도 위에 강제 중첩하지 않음

이 API의 이미지에는 자체 배경지도가 포함되어 있습니다. 영상 픽셀별 WGS84 지리참조는 검증되지 않았습니다.
따라서 영상을 카카오 도로지도에 겹치지 않고 **독립된 영상창**에 실제 영상 그대로 표시합니다.
도로 위치별 강수 판정에는 사용하지 않습니다. 기존 경로별 기상청 격자예보와 별도로 유지합니다.

이 자료는 초단기 **강수예측 분포영상**이며 레이더 **관측 실황**이 아닙니다.

## 다음 기술 게이트: 실제 지도 정합

1. 배경지도 없는 공식 영상 API nph-qpf_ana_imgp 에서 유효한 시각의 실제 JSON/이미지 메타데이터와 좌표계를 검증합니다.
2. 원본 Lambert 격자를 Web Mercator/카카오 지도좌표계에 정확히 재투영합니다. 임의 NE/SW 신축은 금지합니다.
3. 지리 기준점의 정합을 검증한 뒤 지도 이동·확대·회전 및 GPS 주행 성능을 테스트합니다.
4. 실황/예측 구분, 10분 시간 프레임, 이미지 유효시각, 결측 표시, 재배포 허용조건을 별도 검증합니다.
5. 모든 시험 통과 전에는 Production에 반영하지 않습니다.
