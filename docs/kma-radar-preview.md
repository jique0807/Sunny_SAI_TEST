# Sunny SAI — 카카오 지도 위 전국 강수예보 중첩

## 현재 Preview 구현

- 카카오 도로지도/항공지도 유지. 기상청 배경지도 이미지는 사용자에게 표시하지 않음.
- 기상청 전국 5km 초단기 강수예보 RN1 API 실제 조회 성공: https://apihub.kma.go.kr/api/typ01/cgi-bin/url/nph-dfs_vsrt_grd
- 실제 서버 응답은 149×253 = 37,697 격자, 유효 9,295, 결측 28,402, 강수 예보 있는 셀 0개. 그 시각의 무강수 상황에 가짜 강수는 표시하지 않음.
- KMA LCC 5km 격자 인덱스 x=1..149, y=1..253을 위경도로 역변환; Kakao MapProjection.containerPointFromCoords로 실제 지도 픽셀 좌표에 맞춰 4개 모서리의 폴리곤을 캔버스에 칠함.
- 지도 이동·줌·GPS 실시간 내비게이션에 맞춰 렌더링을 최대 약 10Hz로 갱신. 자료가 없는 영역은 색을 임의로 채우지 않음.
- 레이어 버튼: 상단 🌧 강수예보, 표출 메뉴의 전국 강수예보 중첩. 별도 기상청 지도가 포함된 영상창 UI는 제거함.
- 시간 선택 0/+1/+2/+3시간, 실제 발행·예보 유효시각 및 조회상태 표시.
- 서버 보안: GET /api/rain-grid?lead=0..3 은 프리뷰 전용 인증된 세션에서만 사용. 2MiB, 전체 개수 및 값 검증, 요청 제한, 캐시. API 키는 브라우저에 노출하지 않음.
- 일반지도·위성지도 썸네일은 홈 이외 화면에서 강제 숨김. 기존 주행·길찾기·위험 예보는 유지.
- 테스트 브랜치 feature/kma-radar-preview. main 운영 버전 무변경.

## 자료 해석과 남은 게이트

이 레이어는 5km 기상청 강수량 초단기예보이며 레이더 실황/5분 영상/도로 노면 측정값이 아니다.
유효 격자 0mm와 결측(-99)을 구분한다. 결측 지역의 안전 여부는 판정하지 않는다.
500m 레이더 실황 영상을 추가하려면 HSR/PCPH의 실제 접근승인·지리참조·재투영·이용조건을 별도로 검증해야 한다.
실제 모바일 Kakao SDK 연결, 인증 허용 도메인, 강수 상황에서 확대·이동·회전 정합은 직접 테스트가 필요하다.
