# 공통 더미 테스트 구성

공유 원본은 `public/scenarios/shared.json`이며 GitHub 작업 브랜치에 보관한다. 배포된 앱은 더미 시연모드를 처음 열 때 이 파일을 읽어 저장된 구성 목록에 추가한다.

- 공통 테스트 · 자동차: 서울역 → 강남역, 일반 2개 + 긴급 2개
- 공통 테스트 · 도보: 서울역 → 서울시청, 일반 2개 + 긴급 2개
- 각 경로는 실제 카카오 자동차 / TMAP 보행 경로로 탐색한다. 이벤트는 가상 입력자료다.

앱의 ‘현재 구성 저장’은 해당 브라우저에 저장되며 GitHub를 자동 수정하지 않는다. 여러 테스터에게 같은 사용자 구성을 배포하려면 ‘내보내기(JSON)’로 추출한 `scenario` 객체를 `shared.json`의 `scenarios` 배열에 추가하고 프리뷰를 다시 배포한다. 브라우저에 저장된 개인 구성을 임의로 업로드하거나 덮어쓰지 않는다.

시험 위치: 고정 프리뷰 → 더미 시연모드 → ③ 시나리오 저장·불러오기 → 공통 테스트 구성 선택. 메뉴 진입 위치는 기존 더미 시연모드 버튼을 사용한다.

만료된 ITS 고정자료 통합 검사 1개는 요청에 따라 skip 처리했다. 실제 ITS 기능과 나머지 파서·기한·위치 검사는 유지한다.
