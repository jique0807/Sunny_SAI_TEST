## 입력 제한과 구현

- 도로날씨: 관측 후 30분 이내, 경로 250m 이내, 앞으로 10분 이내 통과 지점만 엔진 입력. 인접 평행도로 가능성을 표시하며 같은 도로·차로라고 확정하지 않는다. 맑음 자료는 위험 이벤트를 생성하지 않는다. 화면 OFF와 엔진 수집은 독립이다.
- 신적설: 초단기예보의 강수·기온·바람을 유지하고 단기예보 SNO를 같은 예보시각에만 보완한다. SNO 장애 시 기존 예보를 버리지 않는다. 범위 값은 원문을 유지하며 임의 cm 수치로 바꾸지 않는다. 신적설 발표시각을 따로 보존한다.
- 사고이력: 보행자·어린이·노인 자료를 행정구역별로 수집한다. 좌표·연도·건수를 검사하고 같은 지점 중복을 제거한다. 현재 사고나 사고확률로 해석하지 않는다.
- 환경설정의 데이터 연결 확인에 추가 5개 분야를 포함했다. 미수신 자료를 사용 가능으로 표시하지 않는다.

## 보류 해제에 필요한 확인

1. 기상청 API허브 **지상관측 지점정보 조회 → 1.1.2 AWS** 활용승인. 현재 `stn_inf.php?inf=AWS`가 403이다. 기존 `KMA_API_KEY`는 AWS 관측 수치 요청에는 작동한다.
2. 추가 사고자료 **법규위반 사고다발지역** REST 이용승인·인증키 확인. 기존 보행 사고키를 교체하지 않도록 선택적 `KOROAD_VIOLATION_API_KEY`를 지원한다.
3. **무더위쉼터 정보**의 실제 서비스키 확인. 재난안전 `DSSP-IF-10942`에는 선택적 `HEAT_SHELTER_API_KEY`를 지원한다(없으면 기존 `SAFETYDATA_API_KEY`). 생활안전지도 `IF_0001`의 HTTP 500은 원인이 확정되지 않았다. 시설 수신 후 좌표계·시설 유형·운영 정보를 검증해야 한다.
