# Sunny SAI — Risk Engine / GK2A 통합 개발 점검 (2026-11-10)

## 작업 범위

이 문서는 GitHub 개발 브랜치 `feature/sunny-integrated-tmap-risk-v2-20261110`의 신규 구현을 정리한다.
**프리뷰와 운영 배포는 의도적으로 하지 않았다.** 소스 테스트 성공과 실제 기관 API 수신 성공을 구분한다.

### 1. 설명 가능한 위험판단 엔진

- 규칙 기반(학습형 AI 아님), 사고발생 확률이나 안전 보증 점수로 해석하지 않는다.
- 자동차는 기상청 경로별 예보·공식 기상특보·검증된 도로위험 및 ITS 인접 돌발정보를 참고한다.
- 도보는 보행자 전용 경로의 기상청 예보·기상특보·TAAS 2024년 사고이력을 참고한다.
- 지도 레이어 ON/OFF와 경로 위험판단 자료 수집을 분리한다. 단, `내 경로에 표시`라는 마스터 기능을 끈 경우 경로 위험 안내 수집을 비활성화할 수 있다.
- 기상청 예보는 **실제 경로 지점·예상 통과시각·예보 유효시각** 모두 일치해야 인정한다. 기존 경로의 오래된 예보를 새 경로의 위험으로 재사용하지 않는다.
- 보행사고 집중구역 및 ITS 사고 신고점은 실제 경로의 **120m 이내**, 검증된 도로위험 링크는 **25m 이내**에서만 경로 위험 후보가 된다. 이 수치는 앱의 보수적 위치 검증 조건이며 공식 사고 위험 확률이 아니다.
- 유효시각이 맞지 않는 기상 위험 이벤트는 지도 위험 아이콘·알림에서 제외한다.
- 기상특보 수신 스냅샷의 유효기간은 10분으로 제한한다. GPS 경로 안내 중에는 공식 위험 근거를 약 8분 간격으로 재조회한다(자료 미수신은 안전 판정으로 대체하지 않음).
- 대안 경로 비교는 카카오 실제 도로 형상이 다르고, 기상청 예보 조회율 80% 이상인 후보가 2개 이상인 경우에만 상대적 기상위험 신호를 비교한다. 사용자가 선택해야 경로를 전환한다. ITS·현장 통제·도로 안전이 검증된 우회라고 주장하지 않는다.

### 2. GK2A 위성 3종 공식 API 연결

- 기상청 API허브 위성 API 문서: https://apihub.kma.go.kr/apiList.do?seqApi=6
- 대상은 `RR`(강우강도), `CI`(대류운 발생탐지), `FOG`(위성 안개)뿐이며 **ICING은 제외**한다.
- 서버 전용 인증키 `KMA_API_KEY`를 사용하고 URL·키를 브라우저로 출력하지 않는다.
- 위성 파일목록 API: `/api/typ05/api/GK2A/LE2/{RR|CI|FOG}/KO/imageList`
- 이미지 API: `/api/typ05/api/GK2A/LE2/{RR|CI|FOG}/KO/image`
- 관측시각은 기상청 문서 기준 **UTC(YYYYMMDDHHmm)**. 실제 목록과 일치하는 시간만 이미지를 요청한다.
- 앱 서버 API: `GET /api/gk2a-diagnostic` (3개 산출물 수신 진단), `GET /api/gk2a-catalog?kind=...` (원본 관측시각), `GET /api/gk2a-image?kind=...&utc=...` (최신 관측 원본 이미지, 실제 목록 교차검증).
- 기능: 상품 화이트리스트, 최근 6시간 제한, 기관 원본 PNG 헤더·크기 검사, 요청 횟수 제한, 세션 검증, 비정상 응답 실패 처리.
- 표출 화면: 접을 수 있는 `위성영상 실제 자료 수신 확인`에서 RR/CI/FOG를 선택해 관측시각 목록과 원본 영상을 확인한다.
- **미완료:** 기관별 실제 API 승인 여부, 상품 응답 형식, 영상 배경 투명도, 픽셀↔위경도 좌표 변환, 카카오 지도 중첩 및 위성정보를 AI 위험판단에 투입하는 작업.
- 좌표가 검증되지 않은 원본 영상은 **카카오맵에 중첩하거나 경로 위험도에 입력하지 않는다**. 위성 3종 지도 레이어의 체크박스도 이 조건이 해결되기 전까지 비활성화한다.
- 위성 API가 존재한다는 사실과 각 기관 계정에서 실제 영상이 수신된다는 사실은 다르다. 배포 환경에서 실제 공급기관 응답을 검증해야 한다.

### 3. 좌표 정합의 후속 필수 검증

1. 원본 GK2A 산출물의 영역(KO/EA), 좌표계/투영 및 픽셀 크기를 실제 메타데이터로 검증한다.
2. KMA 제공 공식 GK2A 격자 위경도 API `nph-gk2a_latlon_api` 또는 위경도 NetCDF 파일과 영상 행·열 좌표를 대조한다.
3. PNG 산출물의 배경 알파 채널, 좌표별 유효 마스크, 지도 텍스트 및 경계선 포함 여부를 검증한다.
4. 카카오맵 실제 지도에서 기준점 여러 개와 영상 픽셀 위치의 오차를 측정한다. 임의의 4개 경위도 모서리로 영상을 억지로 늘려 표시하지 않는다.
5. 각 자료의 관측시각, 수신 지연, 결측값을 표시하고 정합 실패 시 자동으로 레이어를 숨긴다.
6. 위성이 제공하는 관측·탐지 결과를 도로 결빙·침수·통제라고 직접 추정하지 않는다.

### 4. 자동차·도보 검증

자동검사는 실제 제공기관이 아닌 모의 응답을 이용한 방어·자료 흐름 시험이다.
- `test/risk-fusion-driving-walking.test.mjs`: 자동차/도보 분리, 예보시각 일치, ITS/TAAS 120m, 도로위험 25m, 일부 자료 누락 시 비교 보류, 특보 TTL.
- `test/gk2a-api-probe.test.mjs`: 서버 공식 GK2A 목록·UTC·이미지 PNG 검증·허용품목·비밀키 비노출.
- `test/gk2a-inspector.test.mjs`: 원본 이미지 확인 전 실제 관측시각 검증, 승인 미확인 시 지도 표시 차단.
- `test/taas-rest-risk-v21.test.mjs`: TAAS REST 유형·좌표·사고건수 검증·카카오맵 마커·안전한 API 경계.
- 기존 `test/gps-integration.test.mjs`, `test/safe-route-engine.test.mjs`, `test/nationwide-walking-risk.test.mjs` 등의 회귀시험 유지.

**아직 수행하지 않은 현장 검증:** 실제 차량·도보 GPS 이동, 위성 영상 위치 정합, 동시 3개 API의 실수신 성능, 소수신·고장·비·눈·통제 발생 시 우회 동작.
