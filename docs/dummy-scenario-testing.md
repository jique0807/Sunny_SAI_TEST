# 더미 시연 사용·확인 방법

## 저장과 파일의 차이

- **이 기기에 저장**: 시나리오 이름, 초기 강수량, 추가 자료 종류·수치, 자료 입력 진행률을 현재 브라우저에 보관한다. 앱 실제 기상자료를 바꾸지 않는다.
- **시나리오 파일 내보내기(JSON)**: 같은 이벤트 조건을 다른 기기에 불러오거나 제출용 모의데이터로 사용할 파일이다. `public/scenarios/`의 기본 예시 파일도 불러올 수 있다.
- **실행 기록 JSON**: 이동 화면에서 받는 결과 파일이다. 실제 선택한 경로, 더미 입력자료, 엔진 판정, 조치, 우회 탐색 시도, 음성 시작·완료·오류를 기록한다. 좌표가 포함되므로 제출할 때 공개 장소를 사용한다.

## 기본 시나리오 11종

폭우·침수경보 / 폭염·대피 / 자료 전체 누락 / 폭우 예보만 수신 / 약한 비 / 위험 신호 없음 / 눈 예보 / 강풍 / 오래된 예보 / 경로 밖 자료 / 일부 예보 누락.

위험 신호 없음은 전체 경로 안전 보증이 아니다. 시나리오의 위험자료는 모두 더미이며 실제 공공기관 발표·관측이 아니다.

## 음성 확인

1. 환경설정의 음성안내를 켠다. 소리는 브라우저·기기의 재생 권한, 음량, 무음 상태와 한국어 음성 지원에 영향을 받는다.
2. 더미 모드에서 비 8 mm/h를 입력하면 100 mm처럼 고정된 시연 수치가 아닌 8 mm를 안내해야 한다.
3. 눈 예보에서 적설량·결빙을 만들어 말하면 안 된다. 폭우·침수, 고온, 강풍은 해당 입력 수치·엔진 결과에 맞춰 안내한다.
4. 더미 모드의 음성 출력 시작·완료·오류는 점검용 실행 기록에만 남고 브리핑에는 표시하지 않는다. 재생 완료 이벤트가 실제 스피커 음량이나 사용자의 청취까지 증명하지는 않는다.
5. 개인 Google 음성이 연결되어 있으면 새 더미 모드에서도 그 음성을 사용하고, 실패하면 오류를 표시한 뒤 기기 음성으로 대체한다.

## 우회 탐색

가상 위험 위치의 양측 근거리 경유지 → 진입·이탈 경유지 → 더 넓은 연결 도로 순으로 탐색한다. 자동차는 실제 차량 도로 경로를 조회하고 도보는 실제 TMAP 보행 경로 구간을 연결한다. 각 후보는 위험영역 회피와 엔진 판정 근거를 확인한 후 선택한다. ‘최단/전역 최적’ 또는 ‘실제 안전’을 보증하지 않는다.

실제 제공자 장애·이용권한 문제, 위험영역 안의 목적지, 회피 가능한 연결 도로 부재 등에서는 경로를 꾸며서 표시하지 않는다. 실패 시 이동을 대기하고 이유·시도 기록과 재탐색 버튼을 제공한다.

프리뷰 전용 실제 연결 검사: `/api/dummy-detour-diagnostic?mode=driving` 또는 `walking`. 입력은 공개된 서울역→강남역 고정 좌표다. 실제 제공자 경로가 더미 위험영역을 피하는지 확인하며 10분간 결과를 재사용한다.
